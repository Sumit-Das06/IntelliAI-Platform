# services/tts-kokoro — Text-to-Speech (Kokoro)

TTS inference service wrapping Kokoro-82M (Apache-2.0, ONNX, CPU real-time).
Arrives in Milestone 3 (v0.4). Voices are individually license-audited before
catalog entry.

> Engine decision changed from Piper at Milestone 1.5 (Piper was archived
> upstream and its successor fork is GPL-3.0) — see
> [FOUNDATION_MODELS.md §3](../../docs/FOUNDATION_MODELS.md). Voice-cloning
> work (Phase 2) targets the Chatterbox lineage, not this service.
