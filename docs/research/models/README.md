# docs/research/models/ — Candidate dossiers

One document per candidate lineage, named `<model>-dossier.md`, per
[RESEARCH_FRAMEWORK.md §11](../RESEARCH_FRAMEWORK.md).

A dossier is created at **Gate 0 (intake)** as a short intake record —
lineage, provenance, claims, and *why this lineage deserves
investigation* — and grows into the full thirteen-section dossier at
**Gate 2 (desk research)**. A dossier is **mandatory** before a candidate
may hold `Promising` or any later status.

**Reading discipline.** At Gate 0, nearly everything in a dossier is a
**claim** (§2): a vendor statement, a model-card field, or a landscape
report. Only items marked *verified at source* with a date are Facts, and
only records in `ml/evaluation` are Evidence. Gate 0 records contain **no
scoring, no ranking, no quality comparison, and no recommendation** — a
candidate's presence here means only that its lineage is worth
investigating.
